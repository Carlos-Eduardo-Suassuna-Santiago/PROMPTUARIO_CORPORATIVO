## Orientações

Formato: Equipe, documento único de até 4 páginas (PDF ou DOCX), aplicado ao produto real do projeto integrador.

Orientação: Planejamento em nível macro e cronograma parcial e com possíveis folgas (como comentado em sala de aula para eventualidades).

|   |   | O que a equipe deve responder |   |
| --- | --- | --- | --- |
|   |   | A · Iniciação |   |
| Identificação |   | Nome do projeto e equipe, gerente do projeto (pode ser um de vocês ou todos) |   |
| Problema, objetivo e valor |   | Qual situação real o produto resolve, para quem, que mudança gera e por que vale a pena |   |
| Projeto, produto e operação |   | O que é o projeto, o que é o produto entregue e qual operação ele sustentará depois |   |
| Escopo e fora do escopo |   | O que será entregue e o que não será |   |
| Partes interessadas (stakeholders) |   | Quem são, o que esperam e como podem ajudar ou atrapalhar |   |
| Restrições, premissas e viabilidade |   | Prazo, equipe, tecnologia e por que vale começar |   |
|   |   | B · Planejamento (nível macro) |   |
| Abordagem e ciclo de vida |   | Preditiva, ágil ou híbrida, justificada pelas características do produto |   |
| Fases, marcos e entregas |   | Linha do tempo do semestre: fases, marcos principais e o que será entregue em cada um |   |
| Papéis e riscos iniciais |   | Quem faz o quê; 3 a 5 principais riscos com causa provável e resposta prevista |   |
|   |   | C · Execução |   |
|   |   | Rotina e ferramentas, definição de "pronto" (3 a 5 critérios) e comunicação com |   |
| Condução do trabalho |   | stakeholders (quem, frequência, formato) |   |
|   |   | D · Monitoramento e controle |   |
|   |   | Mínimo 3 indicadores (o que medir, como, frequência) e o que indica desvio e a ação |   |
| Indicadores e gatilhos |   | correspondente |   |
|   |   | Diante de um pedido novo: quem avalia, quais impactos analisa (escopo, prazo, |   |
| Controle de mudanças |   | qualidade, riscos) e quem decide |   |

## Avaliação:

- Objetivo e escopo (30%)

- Ciclo de vida e planejamento (30%)

- Execução (20%)

- Monitoramento e controle (20%)
